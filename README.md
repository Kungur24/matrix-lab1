# Matrix — Laboratory work 1, variant 13

C++ console application for Visual Studio / CMake.

Variant 13:
- movement: right to left
- shape: zig-zag
- speed: 1–30 characters per second
- line length: 1–30 characters
- epilepsy mode: Y/N

## Build
Open this folder in Visual Studio using **File → Open → Folder**. Visual Studio detects `CMakeLists.txt`, configures the project, then build and run the `matrix` target.

## Command-line examples
- `matrix.exe 23 8 Y`
- `matrix.exe 10 15 N`
- `matrix.exe --help`
- `matrix.exe /?`

The animation runs continuously; stop it with Ctrl+C.
